# CODMOS SURVIVORS v1.0.0

## 다운로드

- Apple Silicon Mac(M1 이상): `CODMOS.SURVIVORS-1.0.0-arm64.dmg`
- Intel Mac: `CODMOS.SURVIVORS-1.0.0-x64.dmg`
- Windows 10/11 Intel·AMD 64비트: `CODMOS.SURVIVORS-Setup-1.0.0-x64.exe`
- macOS ZIP 파일은 DMG를 사용할 수 없을 때 선택하는 대체 패키지입니다.

## macOS Gatekeeper 안내

DMG와 ZIP 자체의 체크섬·압축 검사는 통과했습니다. 현재 macOS 패키지는 Apple Developer ID 서명 및 공증 전이므로 다운로드 후 “손상되어 열 수 없음” 경고가 표시될 수 있습니다.

SHA-256이 아래 값과 일치하는 공식 릴리스 파일에 한해서 다음처럼 격리 속성을 제거한 뒤 열 수 있습니다.

```bash
xattr -d com.apple.quarantine "$HOME/Downloads/CODMOS.SURVIVORS-1.0.0-arm64.dmg"
```

Intel Mac에서는 파일명의 `arm64`를 `x64`로 바꾸어 실행합니다. 일반 사용자에게 경고 없이 배포하려면 추후 유효한 `Developer ID Application` 인증서로 서명하고 Apple 공증을 완료해야 합니다.
