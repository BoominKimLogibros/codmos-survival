# CODMOS SURVIVORS 1.1.1

## 주요 변경

- LAN UDP 협동 플레이의 최대 인원을 20명으로 확장했습니다.
- 진행 중인 게임 참여와 재접속 흐름을 개선했습니다.
- 멀리 있는 파티원, 몬스터, 룬 목표를 확인하는 화면 밖 방향 표시를 추가했습니다.
- 플레이어 보호막, 상태 표시, 무기 현황 HUD를 개선했습니다.
- 협동 플레이의 몬스터, 투사체, 폭발, 룬 동기화와 패킷 안정성을 강화했습니다.
- 웹 브라우저에서는 기존 싱글플레이와 프로필 자동 저장을 그대로 이용할 수 있습니다.

## 다운로드

- Windows 10/11 64비트: `CODMOS.SURVIVORS-Setup-1.1.1-x64.exe`
- macOS Apple Silicon: `CODMOS.SURVIVORS-1.1.1-arm64.dmg`
- macOS Intel: `CODMOS.SURVIVORS-1.1.1-x64.dmg`

LAN 협동 플레이는 같은 네트워크에 연결된 컴퓨터에서 동일한 버전의 앱을 실행해야 합니다. 운영체제가 방화벽 또는 로컬 네트워크 접근을 묻는 경우 허용해 주세요.
