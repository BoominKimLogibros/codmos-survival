# CODMOS SURVIVORS 1.1.0

## 주요 변경

- Electron 기반 2~4인 LAN UDP 협동 플레이 및 방 로비를 제공합니다.
- 동일 컴퓨터의 개발 인스턴스와 같은 LAN 기기 사이의 방 검색을 지원합니다.
- 구형 `.codmos` 파일과 로컬스토리지 프로필을 현재 데이터 구조로 안전하게 보정합니다.
- 자동 난이도, 보스·몬스터 진행, 룬, 부활, 비정지 멀티플레이 레벨업을 적용합니다.
- 프로필, 스킨, 저장, HUD, 스킬 아이콘과 로컬 게임 에셋을 정리했습니다.

## 개발 실행

```bash
npm install
npm run dev:electron
```

Node.js 22.12 이상을 권장합니다.
