# CODMOS SURVIVORS v1.0.1

## LAN UDP 검색 수정

- `255.255.255.255` 고정 브로드캐스트를 제거했습니다.
- 실행 중인 Mac·Windows의 IPv4 네트워크 인터페이스와 넷마스크를 읽어 실제 서브넷 브로드캐스트 주소를 자동 계산합니다.
- Wi-Fi·유선·VPN 등 활성 인터페이스가 여러 개면 각 네트워크에 검색 신호를 전송합니다.
- 네트워크가 바뀌면 다음 1초 검색 주기부터 새 주소를 다시 계산합니다.
- macOS 로컬 네트워크 권한 설명을 앱 번들에 추가했습니다.

같은 Wi-Fi라도 공유기의 AP Isolation·Client Isolation이 켜져 있거나 Windows 방화벽에서 앱을 차단하면 서로 검색할 수 없습니다. macOS에서는 첫 실행 시 로컬 네트워크 접근을 허용해 주세요.

## 다운로드

- Apple Silicon Mac(M1 이상): `CODMOS.SURVIVORS-1.0.1-arm64.dmg`
- Intel Mac: `CODMOS.SURVIVORS-1.0.1-x64.dmg`
- Windows 10/11 Intel·AMD 64비트: `CODMOS.SURVIVORS-Setup-1.0.1-x64.exe`

## macOS Gatekeeper 안내

현재 macOS 패키지는 Apple Developer ID 서명 및 공증 전입니다. 공식 릴리스 파일의 SHA-256을 확인한 뒤 실행이 차단되면 설치된 앱에서 격리 속성을 제거할 수 있습니다.

```bash
sudo xattr -cr "/Applications/CODMOS SURVIVORS.app"
open "/Applications/CODMOS SURVIVORS.app"
```
