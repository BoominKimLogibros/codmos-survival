# CODMOS SURVIVORS 1.1.2

## 주요 변경

- 터치 기기의 싱글·LAN 협동 화면에 우측 하단 8방향 조이스틱을 추가했습니다.
- Windows 앱 창을 리사이즈해도 싱글·협동 나가기 버튼이 새 화면의 우측 하단에 다시 고정되도록 수정했습니다.
- 협동 룬 도전 메시지를 순서 보장 이벤트로 통합하고 안전한 ID 생성 폴백을 적용했습니다.
- 룬은 생성 후 3초 동안 땅에 박힌 이미지로 표시되며, 이후 아이템 룬이 빠르게 솟아오른 뒤 충전할 수 있습니다.
- 공격·방어 룬 발동 순간 해당 룬 SVG 아이콘을 화면 중앙에 표시하고 실제 효과를 동시에 실행합니다.
- 공격 룬은 일반 몬스터를 전멸시키고 각 보스에게 최대 HP의 35% 피해를 주며, 보스 위치에는 강화된 수직 강타와 충격파를 표시합니다.
- 플레이어 보호막은 싱글·협동 모두 `rune-shield.atlas` Spine 애니메이션을 사용하도록 통합했습니다.
- 이탈 플레이어를 `이탈` 유령으로 표시한 뒤 3초 후 관련 오브젝트와 상태를 정리합니다.
- 사망한 플레이어는 비석 위가 아닌 사망 좌표에서 front Spine의 `failure` 모션을 원본 색상·불투명도로 재생합니다. 사망 순간 비석은 화면 위에서 낙하한 뒤 사라지고, 다른 생존자가 해당 위치에 들어온 동안에만 기도 비석과 게이지가 나타나며 10초 연속 기도하면 부활합니다. 단순 이탈 유령은 기존 반투명 `idle` 모션을 유지합니다.
- 프로필 Lv와 스킬 강화 Lv 합계에 따라 소폭·중간·큰·매우 큰 성장 난이도를 적용하고, 자동 난이도 상승 시 일반·압축 몬스터의 체력도 함께 증가하도록 조정했습니다.
- `너무 쉬움` 판정이 2회 연속될 때마다 다음 보스 무리의 동시 등장 수가 1마리씩, 최대 5마리까지 증가합니다. 보스 무리는 마지막 보스를 처치했을 때만 다음 세대로 진행합니다.
- 기존 `whip` 저장 키의 레벨을 그대로 유지하면서 스킬 표시명을 `깃발로 때리기`로 바꾸고, 플레이어 크기의 깃발이 오른쪽은 12시→3시, 왼쪽은 12시→9시로 내려치며 별도의 노란 원호 궤적을 남기도록 교체했습니다. 피해 판정은 손잡이부터 깃발 끝까지 연결되어 중간에 닿은 몬스터도 피해를 받습니다.
- 폭탄 폭발 순간의 원형 그래픽을 9프레임 Spine 연기 폭발 애니메이션으로 교체했습니다.
- 깃발은 내려치는 방향, 회전 구체는 궤도 진행 방향으로 적을 살짝 밀고, 폭탄은 중심에서 바깥으로 크게 밀어냅니다. 번개탄과 오라는 넉백 없이 피해만 줍니다.
- 회전 구체를 1개부터 최대 8개로 조정하고, 구체마다 최초 접촉 1회 및 이탈 후 재접촉 시 다시 피해를 주도록 변경했습니다.
- 몬스터가 떨어뜨리는 체력 회복 아이템을 전용 HP 포션 이미지로 교체하고 경험치 구슬과 비슷한 크기로 맞췄습니다.
- 보스 처치 시 일반 경험치 구슬을 확대하지 않고 전용 경험치 보따리 보상이 나타나도록 변경했습니다.
- 가까운 두 플레이어의 회전 구체가 중앙을 가로지르지 않고 구름 모양의 공유 외곽 궤도를 따라 이동하도록 연결했습니다.
- 게임 스킬 HUD에 HP, 방어력, 이동속도, 자석, 회복을 투자 Lv 아이콘으로 함께 표시하고 hover 상세 정보를 제공합니다.
- 최대 HP·회복 제공 SVG를 적용하고 방어력·이동속도·자석도 같은 플랫 컬러 스타일의 전용 SVG로 통일해 레벨업·게임 HUD·프로필에서 함께 사용합니다.
- 반복 타일과 장식 나무 대신 단색 SVG풍 푸른 성채 아레나 전체 배경을 적용하고, 플레이어와 몬스터가 외곽 성벽을 넘지 못하도록 경계를 맞췄습니다.
- 일반·압축 몬스터의 체력 UI를 제거하고 보스 체력바만 유지했습니다.
- 다섯 Spine 보스를 강타·민첩·중장갑·인라인 돌진·원거리 마법형으로 차별화했습니다. 공격 모션과 바닥 예고 뒤에만 피해가 발생하며, 피격 모션이 있는 보스는 맞을 때마다 해당 모션을 재생합니다.
- 보스 등장 시 공용 `SPAWN` Spine을 한 번 재생한 뒤 각 보스의 고유 `spawn` 모션을 거쳐 `idle` 이동 모션으로 전환하며, 등장 연출 중에는 이동·공격·피격 판정을 차단합니다.
- 보스의 예고 공격 외에도 몸체에 닿으면 기본 공격력의 25% 접촉 피해를 최대 0.6초마다 받습니다. 실제 공격 동작 중에는 접촉 피해를 중복 적용하지 않습니다.
- 보스가 공격을 예고하거나 실행하는 동안에는 공격 Spine 모션을 피격 모션보다 우선 표시합니다. 이 구간에 맞아도 피해 플래시는 유지되지만 피격 모션이 공격 모션을 덮지 않습니다.
- 보스를 한 마리 처치할 때마다 생존한 모든 플레이어가 `success` 모션과 범위 이펙트를 재생합니다. 이 동안 기존 스킬 공격은 멈추고 범위 안 적에게 0.1초마다 플레이어 Lv만큼 넉백 없는 피해를 주며, 각 플레이어는 이동 입력 즉시 축하 상태를 끝내고 전투를 재개합니다.
- 보스 등장 종료 경계 프레임에 HP 바가 중복 생성되어 최초 생성 위치에 남을 수 있던 경쟁 조건을 제거하고, 보스의 현재 위치를 따르는 하나의 HP 바로 통합했습니다.
- 일반·압축 몬스터는 원형 Spine 포탈에서 솟아오른 뒤 추적을 시작하며, 포탈 등장 중에는 이동·공격·피격·물리 충돌 판정을 차단합니다. 협동 참가자도 방장의 생성 종료 시각을 기준으로 같은 연출을 재생합니다.
- 이전 러너 배경·Pathfinder 타일셋·장애물·구형 UI 등 실제로 사용되지 않는 에셋 48개와 해당 프리로드를 제거했습니다.
- 프로필 스킬 현황에도 모든 스탯의 투자 Lv와 현재 수치를 표시합니다.
- 사망 시 레벨 및 강화 스탯 페널티와, 레벨을 소모하는 프로필 스킬 +1 기능을 추가했습니다.
- 스킨 해금 조건에 프로필 레벨과 습득 스킬 강화 레벨을 합산합니다.

## 호환성

- LAN UDP 프로토콜 버전은 `7`입니다. 협동 플레이 참가자는 같은 버전을 사용해야 합니다.
- 저장 형식은 변경하지 않아 1.1.1 프로필과 `.codmos` 파일을 그대로 불러올 수 있습니다.

이 문서는 개발 브랜치 변경 내역이며 설치 패키지 생성이나 배포는 포함하지 않습니다.
